# 一次五字节发送的函数级时间线（原始记录）

环境：Ubuntu ARM64 / 内核 7.0.0-44-generic / 2 vCPU
拓扑：nslab-a(10.77.1.1) --veth-- nslab-b(10.77.1.2)
命令：sudo bpftrace tl3.bt -c 'ip netns exec nslab-a ./netdemo tcp-client 10.77.1.2 18082 5'
说明：nsecs 是单调时钟纳秒；tid 相同表示同一线程；hook= 后是 nf_hook_state.hook。

要点：
1. 27 个点全部是 tid=4443、cpu=0，接收半程没有换成另一个线程。
2. hook=3 是 LOCAL_OUT，hook=4 是 POST_ROUTING，hook=0 是 PRE_ROUTING，hook=1 是 LOCAL_IN。
3. 首末间隔 18665 ns，其中包含 26 个探针的开销，只能看顺序和量级。
