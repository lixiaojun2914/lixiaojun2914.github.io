## 规则计数（同一轮结束后）

$ sudo ip netns exec nslab-r nft list table inet demo
table inet demo {
	chain pre {
		type filter hook prerouting priority raw - 1; policy accept;
		ip saddr 10.77.1.1 meta nftrace set 1
	}

	chain forward {
		type filter hook forward priority filter; policy accept;
		udp dport 18082 counter packets 2 bytes 63 drop
	}
}

说明：规则文件里写的是 priority -301 和 priority 0，nft list 会显示成 raw - 1 和 filter，是同一优先级的符号写法。
